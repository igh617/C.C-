문제 1. 구조체 멤버(문자 배열)에 문자열 넣기

다음은 학생 정보를 저장하는 프로그램이다. 빈칸 (    )에 들어갈 알맞은 것은?

#include <stdio.h>
#include <string.h>

struct Student {
    char name[50];
    int id;
    float gradePoints;
};

int main() {
    struct Student student1;

    (    )(student1.name, "Moon");
    student1.id = 20240001;
    student1.gradePoints = 95.5;

    printf("이름: %s\n", student1.name);
    return 0;
}

1. strcpy
2. strlen
3. strcmp
4. strcat

정답: 1
해설: name은 char 배열이므로 student1.name = "Moon";처럼 직접 대입할 수 없고, strcpy()로 문자열을 복사해야 한다.

struct Student student1 = {"Moon", 20240001, 95.5};
struct Student *p = &student1;

printf("ID: %d\n", p(    )id);

1. .
2. ->
3. &
4. *

정답: 2
해설: 구조체 포인터로 멤버에 접근할 때는 화살표 연산자 ->를 사용한다. ((*p).id와 같은 의미)

문제 3. 중첩 구조체

다음은 구조체 안에 다른 구조체를 멤버로 가지는 코드이다. 빈칸 (    )에 들어갈 알맞은 것은?

struct Date {
    int year;
    int month;
    int day;
};

struct Person {
    char name[50];
    struct Date birthdate;
};

int main() {
    struct Person person1;

    person1.(    ).year = 2000;
    printf("태어난 해: %d\n", person1.birthdate.year);
    return 0;
}

1. Date
2. birthdate
3. person1
4. name

정답: 2
해설: 중첩 구조체의 멤버는 점(.) 연산자를 연속으로 사용해 접근한다. Date는 구조체 이름이고, Person 안의 멤버 변수 이름은 birthdate이다.

문제 4. 구조체 포인터를 함수의 인수로 전달

다음은 함수 안에서 원본 구조체의 점수를 직접 변경하는 코드이다. 빈칸 (    )에 들어갈 알맞은 것은?

void addBonus(struct Student (    ) s) {
    s->gradePoints += 5;
}

int main() {
    struct Student student1 = {"Moon", 20240001, 90.0};

    addBonus(&student1);
    printf("점수: %.2f\n", student1.gradePoints);    // 출력: 점수: 95.00
    return 0;
}

1. &
2. .
3. *
4. []

정답: 3
해설: 구조체 변수의 주소(&student1)를 전달받으려면 매개변수를 구조체 포인터(struct Student *s)로 선언해야 한다. 값으로 전달하면 복사본만 바뀌어 원본에 영향이 없다.

문제 5. 구조체 배열

다음 코드는 구조체 배열에서 두 번째 학생의 이름을 출력한다. 빈칸 (    )에 들어갈 알맞은 것은?

struct Student list[3] = {
    {"Moon", 20240001, 95.5},
    {"Yun",  20240002, 88.5},
    {"Kim",  20240003, 79.0}
};

printf("이름: %s\n", list[(    )].name);    // 출력: 이름: Yun

1. 0
2. 1
3. 2
4. 3

정답: 2
해설: 배열의 인덱스는 0부터 시작하므로 두 번째 요소는 list[1]이다.
